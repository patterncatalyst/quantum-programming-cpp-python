What this tutorial is

A chapter-based, hands-on path to writing real quantum programs, with a primary C++ track and a secondary Python track used for contrast and testing. You build intuition from the state vector up before reaching for a framework, then show each algorithm in C++ (Quantum++, with CUDA-Q's CPU target as a second option) and cross-check it against Python (Qiskit and Aer, Cirq, PennyLane). Everything runs on a normal Fedora workstation in Docker containers, CPU only: no GPU, no cloud account, and no special hardware. The qubit ceiling is about 25 to 30 on a workstation, which is enough for every classic algorithm here.
